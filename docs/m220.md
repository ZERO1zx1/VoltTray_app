# Valkyrie VK M3 Lite: Linux батарейн уншилт

VoltTray нь M220 протоколтой VK M3 Lite хулганын батарейн хувь, цэнэглэж байгаа төлөвийг USB болон 2.4GHz receiver-ээр уншина. Энэ нь Windows драйверийг бүхэлд нь хөрвүүлсэн хувилбар биш; DPI, RGB, товчлуурын тохиргоо, firmware бичих команд хэрэгжүүлээгүй.

## Дэмжлэг ба эрх

| Холболт | USB ID | Interface |
| --- | --- | --- |
| USB кабель | `248a:5d2e` | `02` |
| 2.4GHz receiver | `249a:5c2f` | `02` |

Receiver-ийн USB ID бусад загварт давхцдаг. Уншигч нь interface, report descriptor, хариуны `M220` загвар, checksum, холболтын төлөв, 0–100 хувь зэргийг шалгаж байж батарейг харуулна. Алдаатай эсвэл эрхгүй үед хувь зохиохгүй.

Төслийн үндсэн хавтсаас нэг удаа:

```bash
bash scripts/install-m220-access.sh
```

Энэ скрипт зөвхөн дээрх хоёр ID-ийн мэдээллийн interface-д идэвхтэй локал хэрэглэгчийн `uaccess` эрх олгоно. Шаардлагатай бол хулгана/receiver-ээ салгаж залгаад 30 секунд хүлээж Refresh хийнэ. Шинэ код ажиллахгүй хуучин desktop хувилбар нээлттэй байвал хөгжүүлэлтийн аппыг `npm run tauri:dev` командаар дахин асаана.

## Нэг хулганын хоёр холболт

Ижил USB ID-тай төхөөрөмжүүдийг автоматаар нэг хулгана гэж үзэхгүй. Хэрэглэгчийн баталгаажуулсан хослолыг `$XDG_CONFIG_HOME/app.volttray.monitor/device-pairs.json` (үндсэндээ `~/.config/app.volttray.monitor/device-pairs.json`) файлаас уншина:

```json
{
  "groups": [{
    "id": "confirmed-vk-m3-lite",
    "name": "Valkyrie VK M3 Lite",
    "deviceIds": ["usb:<receiver-physical-path>|0003:0000249a:00005c2f", "usb:<cable-physical-path>|0003:0000248a:00005d2e"]
  }]
}
```

`deviceIds` нь тухайн машины snapshot дахь яг бодит утга байна; дээрх placeholder-ийг шууд ашиглахгүй. Одоогийн машин дээр хэрэглэгчийн баталгаажуулсан хоёр замыг тохируулсан. USB порт соливол physical path өөрчлөгдөж болох тул хослолыг шинэчилнэ. Хоёр холболттой үед нэг карт дээр холболтуудыг харуулж, хүчинтэй батарейн утгыг сонгоно. Нэг холболт үлдсэн ч group ID тогтвортой байна.

## Код ба баталгаажуулалт

- Browser fallback: `src/server/hardware/providers/m220.ts`.
- Native desktop: `src-tauri/src/hardware/m220.rs`.
- Зөвхөн `0x10` info query; report ID 0 + 32-byte payload. Хариу хүлээх хугацаа 500 ms, амжилттай/амжилтгүй уншилтын cache 30 секунд.
- 2026-11-15 бодит төхөөрөмжийн шалгалт: USB **100%, charging**; кабелийг салгасан 2.4GHz **98%, discharging**. TS болон native Rust ижил үр дүн өгсөн. TS snapshot-д нэг `Valkyrie VK M3 Lite` карт гарсан; GUI-г энэ шалгалтаар тусад нь баталгаажуулаагүй.

Бодит төхөөрөмж залгаатай үед native шалгалт:

```bash
cargo test --manifest-path src-tauri/Cargo.toml --locked --offline live_m220_battery -- --ignored --nocapture
```
